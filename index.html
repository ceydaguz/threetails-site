For operators

Integrate once.
Launch every game.

1

Get your API key

We issue a server-to-server key for your platform.

2

Connect your wallet

Give us one wallet URL + secret. We call it (HMAC-signed) for every bet, win and rollback — your balance stays the source of truth.

3

Launch a game

Call our launch endpoint with a player + currency; we return a ready-to-open game URL.

4

Tune per market

Set RTP, limits and currency per operator — inside each game's certified band.

// your backend → Three Tails RGS
POST /api/operator/launch
X-API-Key: "3a1c…f0.9d5b…"
{
  "gameId": "pirates-fortune",
  "currency": "USD",
  "extPlayerId": "player-7781"
}

// ← response
{
  "launchUrl": "https://pirates…?token=…",
  "config": { "rtp": 0.95, "minBet": 1 }
}
